# Sprint 7

## Описание

Автотесты API учебного сервиса Яндекс Самокат.

В проекте реализованы проверки API для курьеров и заказов.

## Технологии

- Python
- pytest
- requests
- Allure

## Тестируемые ручки

### Создание курьера

Проверяется:

- успешное создание курьера
- создание курьера с существующим логином
- создание курьера без login
- создание курьера без password

### Авторизация курьера

Проверяется:

- успешная авторизация
- неправильный login
- неправильный password
- отсутствие login
- несуществующий пользователь

Тест без password временно отключён, так как API не возвращает ответ и запрос зависает

### Создание заказа

Проверяется создание заказа:

- с чёрным цветом
- с серым цветом
- с двумя цветами
- без указания цвета

### Получение списка заказов

Проверяется успешное получение списка заказов

### Дополнительное задание

Реализованы проверки:

- удаление курьера
- принятие заказа
- получение заказа по его номеру

## Запуск тестов

Для запуска всех тестов:

```bash
pytest -v
```
