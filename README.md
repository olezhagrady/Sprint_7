# Sprint 7

## Описание

Автотесты API учебного сервиса Яндекс Самокат.

В проекте реализованы проверки API для курьеров и заказов.

## Технологии

- Python
- pytest
- requests
- Allure

## Структура проекта

- `api.py` — методы для работы с API
- `data.py` — тестовые данные
- `helpers.py` — генерация тестовых данных
- `conftest.py` — фикстуры и предусловия
- `test_create_courier.py` — тесты создания курьера
- `test_login_courier.py` — тесты авторизации курьера
- `test_create_order.py` — тесты создания заказа
- `test_get_orders.py` — тест получения списка заказов
- `test_delete_courier.py` — тесты удаления курьера
- `test_accept_order.py` — тесты принятия заказа
- `test_get_order.py` — тесты получения заказа по номеру

## Тестируемые ручки

### Создание курьера

Проверяется:

- успешное создание курьера
- создание курьера с существующим логином
- создание курьера без логина
- создание курьера без пароля

### Авторизация курьера

Проверяется:

- успешная авторизация
- неправильный логин
- неправильный пароль
- отсутствие логина
- пустой пароль

### Создание заказа

Проверяется:

- создание заказа без цвета
- создание заказа с чёрным цветом
- создание заказа с серым цветом
- создание заказа с двумя цветами

### Получение списка заказов

Проверяется успешное получение списка заказов.

### Удаление курьера

Проверяется:

- успешное удаление
- удаление без идентификатора
- удаление с несуществующим идентификатором

### Принятие заказа

Проверяется:

- успешное принятие заказа курьером
- принятие заказа без идентификатора курьера

### Получение заказа по номеру

Проверяется:

- получение заказа по номеру
- запрос без номера
- запрос с несуществующим номером
